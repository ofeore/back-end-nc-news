NC News API

Base URL: https://back-end-nc-news-71fp.onrender.com

All routes are under /api. Responses are JSON.

Endpoints

GET /api/topics

Get all topics.

GET https://back-end-nc-news-71fp.onrender.com/api/topics

{
  "topics": [
    { "slug": "coding", "description": "..." }
  ]
}
GET /api/articles

Get all articles. Query: sort_by, order, topic

GET https://back-end-nc-news-71fp.onrender.com/api/articles?sort_by=created_at&order=desc

{
  "articles": [
    {
      "article_id": 1,
      "title": "...",
      "topic": "coding",
      "author": "butter_bridge",
      "votes": 0,
      "comment_count": 13
    }
  ]
}
GET /api/articles/:article_id

Get one article (includes comment_count).

GET https://back-end-nc-news-71fp.onrender.com/api/articles/1

{
  "article": {
    "article_id": 1,
    "title": "...",
    "body": "...",
    "comment_count": 13
  }
}
PATCH /api/articles/:article_id

Update votes on an article.

PATCH https://back-end-nc-news-71fp.onrender.com/api/articles/1 


 { "increment_votes": "1"  }
GET /api/articles/:article_id/comments

Get comments for an article.

GET https://back-end-nc-news-71fp.onrender.com/api/articles/1/comments

{
  "comments": [
    {
      "comment_id": 2,
      "author": "icellusedkars",
      "body": "..."
    }
  ]
}
POST /api/articles/:article_id/comments

Post a new comment to an article.

POST https://back-end-nc-news-71fp.onrender.com/api/articles/1/comments 

  { username: "butter_bridge", body: "hello world" }
DELETE /api/comments/:comment_id

Delete a comment by id (204 No Content).

DELETE https://back-end-nc-news-71fp.onrender.com/api/comments/1 

HTTP 204 No Content
GET /api/users

Get all users.

GET https://back-end-nc-news-71fp.onrender.com/api/users

{
  "users": [
    { "username": "butter_bridge", "name": "Jonny" }
  ]
}
Errors: you usually return JSON like { "msg": "Bad request" } or { "msg": "Not found" }.
